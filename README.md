# 🎨 ComicCraft - AI Comic Generator

An AI-powered application that generates creative comics from text prompts using Generative AI.

### 🚀 Live Demo & Project Link
**GitHub Repository:** https://github.com/ven-nilak/ComicCraft

### ✨ Features
- 📝 Text-to-Comic Generation - Convert your story ideas into visual comics
- 🎨 AI-Powered Art - High-quality comic-style images using Stable Diffusion
- 📖 Multiple Panels - Generate complete comic strips with consistent characters
- ⚡ Fast & Easy - Simple and intuitive user interface
- 💾 Download & Share - Save your comics easily

### 🛠️ Tech Stack
- **Frontend:** Streamlit / Gradio
- **Backend:** Python
- **AI Models:** Stable Diffusion, Hugging Face Diffusers
- **Libraries:** Transformers, Pillow, Torch
